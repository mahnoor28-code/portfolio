04. Selected Works

My Projects

HeadlessHydra — Combobox Library

A headless useCombobox<TItem> React hook built for the Khizex Frontend Engineering Internship. Solves the problem of shipping a fully accessible, unstyled combobox that any team can drop into their own design system without fighting a component library's CSS.

  • Full ARIA combobox pattern with complete keyboard navigation.
  • Sync and async filtering, plus multi-select with chip rendering.
  • Event delegation for performance on large, dynamic option lists.
React 18 Strict TypeScript Vite ARIA

Ping — Real-Time Messenger

A chat interface that stays calm and correct while messages arrive asynchronously, mid-type, or in bursts. Solves smart auto-scroll (never yanking a user who's reading history) and non-blocking input while a mock WebSocket transport pushes live traffic.

  • Smart auto-scroll with a "New messages ↓" affordance instead of a forced jump.
  • Read receipts (sent → delivered → read) over a realistic mock transport.
  • Zero any in the codebase; aria-live regions for screen readers.
React 18 Strict TypeScript useReducer a11y

3D Scroll-Driven Landing Page 9.5/10

An Apple-style product page where a 3D model rotates, lifts, and reframes in lockstep with scroll position. Solves the "pinned section that scrubs forward and backward exactly" problem using GSAP ScrollTrigger and Lenis smooth scroll.

  • Typed keyframe timeline drives model rotation, position, and camera distance.
  • Auto-fallback to a static image for no-WebGL, reduced-motion, or low-memory devices.
  • 3D scene code-split and lazy-mounted; render loop pauses when off-screen.
React + Three.js GSAP ScrollTrigger Lenis

Offline-First Shoe Store

A shoe store frontend built around one idea: the network is going to misbehave, and the UI should keep working anyway. 3D product viewing is the visual centerpiece; a hand-written offline queue is the actual engineering point.

  • Hand-written Service Worker queues failed requests and flushes on reconnect.
  • Cart logic lives entirely in a Web Worker, persisted to raw IndexedDB.
  • A finite state machine physically blocks checkout while a sync is pending.
React + Three.js Service Workers IndexedDB
